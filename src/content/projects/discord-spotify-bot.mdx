A Discord bot that integrates with Spotify's API to display detailed information about
80M+ songs.

## Highlights

- Built with [discord.py](https://discordpy.readthedocs.io/) and
  [Spotipy](https://spotipy.readthedocs.io/).
- Intuitive search features for artists and songs, used by 25+ people.
- Data retrieval and response times improved by roughly 250% using asynchronous
  functions.
