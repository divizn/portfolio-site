A practice project built to learn SvelteKit's data fetching, now serving one quote a
day rather than a fresh one per visit.

The quote of the day is cached in Upstash Redis under a date-stamped key, so everyone
gets the same quote until midnight. The first visit of the day fetches and writes it,
and concurrent first visits settle on one another's value rather than racing. If Redis
or the quote API is unavailable the page still renders, just without the caching or
with a fallback quote.

## Status

- **Daily quote**: done, cached in Redis and keyed on the London date.
- **UI**: rebuilt to share the design system used across the rest of phons.dev.

A learning project, not actively maintained.
